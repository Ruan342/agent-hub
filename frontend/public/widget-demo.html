Como Instalar em Seu Site

📋 Instruções de Instalação:

  1. No dashboard do VoiceAI Hub, vá em Integrações
  2. Clique em Widget de Chat → Adicionar
  3. Configure nome, cor, posição e mensagem de saudação
  4. Copie o código gerado
  5. Cole antes do </body> do seu site
  6. Pronto! O widget aparecerá automaticamente 🎉

Código de Instalação

Cole este código no HTML do seu site:

<!-- VoiceAI Widget --> <script src="http://localhost:8000/voiceai-widget.js"></script> <script> VoiceAIWidget.init({ apiKey: 'sua_api_key_aqui', apiUrl: 'http://localhost:8000/api', themeColor: '#7C3AED', position: 'bottom-right', greetingMessage: 'Olá! Como posso ajudar?', voiceEnabled: true, textEnabled: true, agentName: 'Assistente Virtual' }); </script> <!-- End VoiceAI Widget -->

Opções de Customização

🎨 themeColor

Cor principal do widget. Exemplos: #7C3AED, #FF6B6B, #4ECDC4

📍 position

Posição na tela: bottom-right ou bottom-left

💬 greetingMessage

Primeira mensagem que o usuário vê ao abrir o chat

🎤 voiceEnabled

Habilita/desabilita o botão de voz (true ou false)
