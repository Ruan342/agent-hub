<product_requirements>
The project is to build VoiceAI Hub, an online platform where clients can purchase monthly subscriptions to voice-based AI agents. These agents, generated using ElevenLabs, are intended for integration into client systems like CRMs, WhatsApp, and email.

**Core Features Implemented:**
- **Marketplace:** A public page where users can browse and view details of available AI agents, each represented by a cartoon mascot.
- **Voice Testing:** Unauthenticated users can test an agent's voice up to three times from the agent's detail page. Usage is tracked by IP address.
- **User Authentication:** A JWT-based system for user registration and login, with distinct roles for 'admin' and 'client'.
- **Admin Dashboard:** A protected area for administrators to add new AI agents (including uploading mascot images), view custom agent requests, and manage the platform.
- **Client Dashboard:** A protected area for subscribed customers to manage their agents, view API keys, and see usage analytics.
- **Payments:** Stripe integration for handling monthly subscription payments.
- **API & Billing Pages:** Dedicated pages for API documentation and customer billing management.
- **ElevenLabs Integration:** The platform is connected to the ElevenLabs API to generate voice audio in real-time.
</product_requirements>

<key_technical_concepts>
- **Backend:** FastAPI (Python)
- **Frontend:** React.js
- **Database:** MongoDB
- **Authentication:** JWT (JSON Web Tokens)
- **Payments:** Stripe API
- **Voice Synthesis:** ElevenLabs API
- **Styling:** Tailwind CSS, Shadcn UI components
- **File Storage:** Local server-side storage for uploaded agent mascot images.
- **Rate Limiting:** IP-based tracking for public API endpoints (voice testing).
</key_technical_concepts>
