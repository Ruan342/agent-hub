<product_requirements>
The project, VoiceAI Hub, is a platform for selling subscriptions to specialized, multilingual voice AI agents.

**Implemented Functionality:**
-   **Admin Dashboard:** Full lifecycle management for AI agents (create, edit, delete, duplicate). The agent catalog was recently updated based on a user-provided document, resulting in 23 active agents.
-   **Marketplace:** A public-facing page where users can browse and filter the 23 available agents. A Login button was added for unauthenticated users.
-   **Client Dashboard:** A page for subscribed users to view their purchased agents.
-   **Agent Interaction Page ():** This is the core user-facing feature. It was completely redesigned to be a hybrid of two concepts:
    1.  **Sintra-style UI:** A left sidebar displays a history of all past conversations, allowing users to switch between them. A + Nova Conversa button initiates a new session.
    2.  **ChatGPT Voice-style Interaction:** A real-time, hands-free voice mode with visual indicators for listening/speaking, live transcription, automatic audio playback of agent responses, and the ability to interrupt the agent mid-speech.
-   **Agent Configuration:** Within the chat page, users can access tabs to configure the agent's context (e.g., company name, product), view/copy their API key, and see placeholders for future integrations (WhatsApp, CRM).
